Baleia — Recorrido virtual 360°

Esta página es la demo de "sitio de un tercero" pedida para verificar el circuito completo del embed: es un HTML suelto, sin build ni servidor propio, con el snippet real tal cual se le entregaría a un cliente (ver README de @r360/embed, sección "Snippets por plataforma"). Se puede abrir haciendo doble clic en el archivo.

Nota sobre file://: abierto por doble clic, el navegador trata esta página como un origen "opaco" (sin http/https), así que location.origin no es un origen válido y el parámetro parentOrigin que arma el loader no sirve — el visor tampoco puede caer a document.referrer (los navegadores no lo mandan desde file://). El resultado esperado en ese caso: el tour intenta cargar y, a los 8s sin handshake, dispara tm:loadError en el log de abajo — es el comportamiento correcto del loader ante un origen que no puede validar, no un bug. Para probar el circuito COMPLETO de verdad (con tour:hello/tour:ready llegando), serví este archivo con cualquier servidor estático, por ejemplo desde apps/embed/demo/: python3 -m http.server 8095 y abrí http://localhost:8095/sitio-tercero.html.
