# El mínimo indispensable para que exista un producto

> Guía interna. Responde una pregunta distinta a la del Brief Maestro (`01-CLIENTE/1`): ese documento lista todo lo que **idealmente** querríamos para un recorrido 360° completo. Este documento responde algo más chico: **¿cuál es el piso absoluto por debajo del cual no hay nada que vender?**

## Por qué esta distinción importa

El Brief Maestro marca varias cosas como "obligatorio" porque son obligatorias **para el recorrido 360° completo**. Pero un cliente en Nivel 0 de la escalera (ver `2-Escalera-de-Niveles-de-Material.md`) no tiene panorámicas, y aun así puede tener un producto vendible: un masterplan interactivo. Este documento separa qué es imprescindible para *cualquier* producto, qué es deseable, y qué es lujo — para no perder un cliente chico por pedirle de entrada la lista completa del brief maestro.

---

## Imprescindible — sin esto no hay producto, punto

1. **Un plano o imagen del conjunto**, aunque sea de baja calidad (foto de una foto, PDF de baja resolución, imagen satelital). Sin esto no hay sobre qué dibujar polígonos ni qué mostrar como base visual. Si ni siquiera esto existe, no es un cliente con "poco material" — es un cliente que todavía no tiene proyecto para mostrar.
2. **Un listado mínimo de unidades**: cuántas hay, con qué nombre/código se identifican, y algún dato básico (superficie o tipología). No hace falta la planilla completa del brief maestro (`01-CLIENTE/4`) para arrancar, pero sin esto no hay nada clickeable — el mapa sería decorativo, no interactivo.
3. **Un nombre y una identidad mínima**: el nombre del proyecto y, si es posible, un logo (aunque sea en JPG de baja calidad, para redibujar). Sin esto el producto queda anónimo, lo cual en la práctica ningún cliente acepta.

## Deseable — mejora mucho el producto, pero no lo bloquea

- Renders o fotos exteriores (aunque sean pocos y de resolución media) — sin esto el producto es un mapa técnico, con esto ya transmite algo del proyecto real.
- Datos comerciales completos (precio, condiciones, estado) — se puede lanzar con estado comercial oculto o "a consultar" y completarlo después.
- Plantas por tipología — mejoran mucho la ficha de cada unidad, pero el producto funciona sin ellas (ficha con datos de texto solamente).
- Textos descriptivos propios — si no están, se redactan a partir del brochure (ver Brief Maestro, sección 8).

## Lujo — suma mucho, pero es la parte que casi nunca llega en la primera entrega

- Panorámicas 360° (de render o reales) — es la pieza que separa un "mapa interactivo" de un "recorrido 360°" real, pero **no es indispensable para que exista un primer producto vendible**.
- Video de drone o vuelo aéreo real.
- GeoJSON de agrimensura (ahorra semanas de dibujo manual, pero su ausencia no bloquea nada, solo suma tiempo).
- Fotografía de obra o de avance de construcción.
- Modelo 3D navegable propio (más allá de las panorámicas ya renderizadas).

---

## Regla de decisión rápida

Si un cliente nuevo tiene los tres imprescindibles (plano, listado de unidades, identidad mínima) → **hay proyecto, se cotiza Nivel 0 como piso** y se conversa qué escalón más se puede sumar con lo que ya tiene.

Si falta alguno de los tres imprescindibles → antes de cotizar nada, resolver ese faltante primero (ver el guion de preguntas en `4-Guion-Para-Destapar-Material.md` — casi siempre el material "no existe" porque nadie le preguntó al lugar correcto, no porque realmente no exista).
